## Welcome to DATASET_VISUAL_EXPLORER

This application loads a CSV dataset, analyze the data and provides a quick overview including:

- Concentration
- Dispersion
- Rare values
- Biases



## Structure

DATASET_TERMINAL/
│
├── datasets/
│   └── CSV files
├── outputs/
│   └── Figure files
│
├── main.py
│   └── Orchestrates the application workflow
│
├── loader.py
│   └── Loads and validates CSV datasets
│
├── analyzer.py
│   └── Performs data analysis and generates statistics
│
└── visualizer.py
    └── Displays summarized results and insights
